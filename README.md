# trackstarr

Work in progress, not ready for use.

Keeps a media library's audio and subtitle tracks tidy, driven by Radarr and
Sonarr webhooks. Drops unwanted language tracks and embedded cover art,
guarantees a non-commentary stereo track downmixed from the best surviving
surround track, and orders what remains. Stream copy apart from the downmix,
no video transcoding.

Hence the name, it excels at tracks.
