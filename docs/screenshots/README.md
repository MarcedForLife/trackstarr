# README screenshots

Use the [local demo](../../web/README.md#demo) at 414 × 896 CSS pixels and 2× resolution, with the
dark Brass theme and Medium posters. Dismiss the demo notice and move the pointer off controls.

1. For `processing.png`, skip Coffee Run's queued import so only the sweep remains. Capture Sintel
   encoding with the overall ETA visible.
2. For `library.png`, reload, stop all processing and wait for the idle logo. Open Library and
   select Medium under View.
3. For `plan.png`, search for Sintel and open its title sheet to show the stereo downmix and
   subtitle removals. Navigate without reloading to stay idle.
